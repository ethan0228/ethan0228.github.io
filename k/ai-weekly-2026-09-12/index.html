    一週總覽

    這週 AI 新聞的主線很清楚：agent 開始從「回答問題」走向「操作流程」，因此所有相關問題一起變重要，包括權限、token、記憶、瀏覽器邊界、公共服務承載、專業責任、模型供給、算力成本與資料在地化。

    趨勢一：Agent 治理從「說錯話」升級為「做錯事」

    本週 agent 安全已經不只是幻覺或拒答，而是「能不能安全地做事」。9/8 AWS AgentCore memory 把記憶保留、過期、隱私、治理拉到工程層；9/9 Claude token 被竊，提醒 AI 工具憑證已成高價值攻擊目標；同日精誠資訊談到 AI agent 從說錯話走向做錯事，直接點出流程與工具操作風險；9/11 公共服務與 CAPTCHA 議題顯示，當 agent 開始替人提交表單、申請服務、查詢系統，原本為人類頻率設計的社會流程會被壓力測試；9/12 Anthropic 威脅情報又把濫用情境拉到台灣防空與生物武器研究。

    agent 越實用，就越需要權限隔離、記憶清理、token 保護、rate limit、審計、停止條件與人工確認點。

    趨勢二：Coding agent 進入大型重構與工程方法論轉換

    這週 coding agent 的訊號不再只是「AI 會寫程式」。9/7 Rails 創始人 DHH 轉向 AI 寫碼，代表工程文化開始接受自然語言、規格與 prompt 成為新的開發介面；9/8 AWS 把 AgentCore 放進 AI-driven development lifecycle，表示 coding agent 正被放進需求、開發、測試、部署等完整 SDLC；9/9 Bun 創辦人用 AI agent 11 天完成跨語言重構，則把 agent 能力推到大型 codebase 遷移與工程管理層級；Cognition 高估值也說明 AI coding 市場還在重排，沒有單一產品贏者全拿。

    跨天整合來看，coding agent 的重點正在從「會不會寫」變成「人如何定義架構、切任務、驗收、控風險」。Bun 案例尤其值得追，因為主軸是「人設框架、AI 產出」：人仍負責架構、規格、審查與判斷。

    趨勢四：模型與 agent 經濟學由成本、配額、蒸餾與商業化壓力主導

    AI 使用量進入規模化後，模型選擇正在從「最聰明」轉成「最適合、最划算、最可靠」。9/8 TechNews 指出 token 使用量暴增後，企業更在意任務總成本；9/11 OpenAI 因 Astra 需求暫停 Pro subscriptions，顯示高能力模型的供給、排隊、配額、價格都會直接影響工作流；Anthropic 揭露 Alibaba、Moonshot AI、DeepSeek 的蒸餾活動，讓模型能力擴散與 API governance 成為平台衝突點；9/12 Garry Tan 主張美國 open-weight labs 也要能蒸餾 frontier models，Moonshot AI 目標年營收 20 億美元，也顯示模型公司正面對商業化壓力。

    這條趨勢的核心不是便宜模型勝出，而是模型路由與任務分級。高風險、長上下文、專業判斷任務需要高能力模型；例行摘要、候選篩選、格式整理、低風險工作可以用中階模型或批次任務處理。成本不是單次 prompt，而是長任務裡所有 token、工具調用、重試、等待與人工驗收的總和。

    趨勢五：AI 基礎設施擴大成算力、資料、台灣供應鏈與在地評測問題

    這週 AI infra 的新聞從 GPU 延伸到整個系統。9/6 HBM 共享記憶體池、800VDC 資料中心供電，9/7 Google 擴建士林研發中心與 AI 晶片功耗飆升，9/8 agentic AI 反過來改變 inference、記憶體與晶片架構需求，9/9 NVIDIA 把 AI factory 比喻為下一個電廠且台灣是核心，9/11 MIT Technology Review 說 AI 供電是架構問題，9/12 Nscale 的 IPO 訊號與 Mecka AI 的機器人訓練資料估值又提醒：AI infra 不只有算力，也包含資料、資料取得成本與真實世界訓練環境。

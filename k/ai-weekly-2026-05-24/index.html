AI 趨勢週報｜2026 5/18–5/24

    本週 AI 產業迎來多條主軸同步推進：Google I/O 2026 正式把平台押注在 agent、生態與搜尋改造；企業級 agent 從 demo 走向正式部署（AWS Bedrock AgentCore、OpenAI Codex+Dell）；NVIDIA 與算力基礎設施仍然是底層驅動；Anthropic 在人才、財務與算力佈局上加速。以下是本週核心趨勢與值得追蹤的重點。

    趨勢一：Google I/O 2026 — 全面 Agent 化

    本週最大事件是 Google I/O 2026，Google 發布了一系列環繞 agent 的產品更新：

    • Gemini 3.5 Flash：低延遲、高性價比，作為多 agent 並行執行的基礎模型單元。Google 明確表示未來將走向「Pro 規劃 + Flash 執行」的分工架構。
    • Antigravity 2.0：從單一 coding app 升級為 agent workflow 平台，可同時編排多個 agent、設計 subagent 流程、排程背景任務。
    • Gemini Spark：24/7 常駐型個人 AI agent，整合 Gmail、Docs、Sheets、Chrome，原生支援 MCP。這被視為對標 OpenClaw 24/7 AI Agent 的產品。
    • Search agentic：Google Search 從「查資料」變成「持續監控與執行任務」，可建立多個客製化 AI agents，條件達成時主動通知。
    • Android CLI 1.0：把 Android 開發專業知識標準化，讓所有 coding agents（Claude Code、Codex、Antigravity）都能開發 Android app。

    為什麼重要：Google 的策略很清楚——消費者入口用 Search/Gmail，開發者入口用 Antigravity/Android CLI，底層用 Gemini Flash 做 agent 執行。這是一條從模型到平台到入口的完整 agent 鏈。

    趨勢二：企業級 Agent 正式起飛

    從 AWS 到 OpenAI，本週釋出多個企業部署信號：

    • AWS Bedrock AgentCore：密集發布多租戶 agent、突破 context window、MCP Server 整合、BI dashboard automation、招募 workflow、醫療 workflow。這些不是 demo，而是企業級 runtime 可用的功能。
    • OpenAI Codex + Dell：把 Codex 帶進 hybrid 與 on-premise 企業環境，対応企業資料邊界與安全治理需求。
    • OpenAI Codex + Ramp：Ramp 工程團隊用 Codex 加速 code review，讓 reviewer 更快定位風險與處理重複檢查。這是 coding agent 進入真實工程流程的案例。
    • SageMaker OpenAI-compatible API：降低應用從 OpenAI API 切到企業端點的成本，讓「OpenAI API 介面」成為事實標準。

    為什麼重要：agent 從實驗室 demo 走向企業部署的訊號明確。多租戶、資料邊界、MCP 整合是企業採用的核心前提。

    趨勢三：NVIDIA — 算力依然是底層驅動

    • Q1 營收再創新高：AI 晶片需求持續高漲。
    • 揭露 430 億美元新創投資：NVIDIA 不只是供應商，也在深度參與 AI 生態配置。
    • 黃仁勳找到全新 2,000 億美元市場：指向 CPU、機器人、邊緣與工業場景。
    • Vera Rubin 量產：下半年台灣供應鏈會很忙碌，下一代 NVIDIA 平台進入量產節奏。

    為什麼重要：算力供給與成本仍是 AI 產業的底層約束。NVIDIA 的市場擴張直接影響模型成本、供應鏈與競爭格局。

    趨勢四：Anthropic — 加速攻勢

    • 首個獲利季度：前哨模型公司開始證明商業化可行性。
    • Andrej Karpathy 加入 pre-training：投入預訓練研究，強化基礎模型能力。人才流向反映技術戰略。
    • 每月支付 xAI 12.5 億美元算力費：凸顯 frontier AI 的訓練與推論成本級距，算力已成為戰略資產。
    • 收購 Stainless：把 SDK / API 連接能力內部化，搶占開發者基礎設施。

    為什麼重要：Anthropic 正在多條戰線（人才、財務、算力、工具鏈）同時推進，是 OpenAI 最主要的核心競爭者。

    趨勢五：醫療 AI 從概念走向合規

    • Amazon Nova Act 取得 HIPAA eligible：開始進入嚴格的企業採購流程。
    • AWS 放射科 workflow agents：把排程、任務分派、資料流交給 agent 系統。
    • AdventHealth + OpenAI：whole-person care 案例，流程改善與資料輔助。

    為什麼重要：醫療合規是高門檻市場，HIPAA eligible 是enterprise AI 進入醫療場景的必要認證。

    趨勢六：World Models 走向真實世界資料

    • NVIDIA Cosmos Predict 2.5：支援 LoRA/DoRA 微調，單 GPU 最低 80GB，可針對機器人操作生成合成軌跡。
    • Google Genie + Street View：把 20 年、超過 2,800 億張 Street View 影像接入世界模型，可用於教育、遊戲、城市模擬、機器人訓練與自駕模擬。

    為什麼重要：世界模型正在從 demo 走向真實資料整合與可客製化，這是 embodied AI 與 robotics 的關鍵基礎。

    趨勢七：AI 搜尋與內容治理

    • Google Search agentic：從查資料變成持續監控與行動入口，挑戰傳統 SEO 與內容出版者商業模式。
    • AI 搜尋新創快速升溫：Perplexity 等新創持續挑戰 Google 搜尋護城河。
    • OpenAI 採用 C2PA + Google SynthID：AI 圖像來源驗證開始跨平台互通。
    • Apple 新 Siri 可能主打隱私：自動刪除對話功能，隱私作為差異化敘事。

    為什麼重要：搜尋是網路流量與知識分發的核心，agentic search 可能是 AI 對網路生態最深層的改寫。

    本週其他值得保留的觀察

    • 華盛頓大學 CS 院長：AI 時代寫程式的核心從語法轉向精準邏輯與系統設計。這直接關係到 AI coding agent 普及後，工程師該補哪種能力。
    • 車廠掀起 AI 技能軍備競賽：GM 裁掉 IT 部門招聘 AI 人才，AI 不只在改變純軟體公司，也在重塑汽車、交通與工業企業的人才結構。
    • Cerebras 上市：AI 算力資本正從 SaaS 轉向硬科技與實體世界。
    • 馬斯克與 OpenAI 訴訟：AI 公司治理的核心問題變成「誰值得信任」，這從抽象倫理變成法律與資本市場問題。
    • PaddleOCR 3.5 接上 Transformers：文件 AI 與 RAG 前處理更容易進入 Hugging Face 生態，解決很多 agent 的瓶頸。

    下週觀察重點

    1. Google agent 生態實際落地速度：Gemini Spark 開放測試、Antigravity 2.0 開發者採用情況
    2. AWS Bedrock AgentCore 多租戶架構：企業級 agent 的營運模型是否可行
    3. NVIDIA Vera Rubin 量產進度：供應鏈與 GPU 供給何時舒緩
    4. Anthropic 獲利持續性：首季獲利是否是「快閃」還是有持續性
    5. AI 搜尋 adoption：Perplexity 之外，agentic Search 是否能改變使用者行為
